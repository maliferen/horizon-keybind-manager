# Changelog

## 0.1.0

- Search by action, mod name, keyboard key, or mouse button in **Options → Controls → Key Binds**.
- Filter conflicts and jump between actions that share a binding.
- Rebind and reset native mod keys from the same list.
- English and Russian interface labels.

Requires Horizon Minecraft 26.3. Tested in-game with Horizon Minimap and World Map. The bundle was verified on Horizon revisions `2ebf00a` and `fdc87ae`.
