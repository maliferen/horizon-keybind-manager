# Horizon Keybind Manager

Поиск назначенных клавиш и исправление конфликтов между управлением игрой и нативными модами в Horizon Minecraft 26.3.

[Скачать v0.1.0](https://github.com/maliferen/horizon-keybind-manager/releases/tag/v0.1.0) · [English](README.md)

Откройте **Настройки → Управление → Назначение клавиш**.

- Ищите по названию действия, мода или клавиши. Запрос `key:M` найдёт точное назначение.
- **Только конфликты** покажет действия с одинаковой клавишей. Кнопка **!** переводит фокус на следующее действие в группе.
- Меняйте и сбрасывайте назначения игры и нативных модов прямо в списке. Настройки сохраняются обычным способом.

## Установка

1. Скачайте `horizon_keybind_manager-0.1.0.hnmod` из [релизов](https://github.com/maliferen/horizon-keybind-manager/releases).
2. Поместите файл в папку `horizon-native-mods/` вашего экземпляра и включите мод в лаунчере Horizon.
3. Соберите и запустите экземпляр с нативными модами.

Для отключения выключите мод в лаунчере и пересоберите экземпляр. Мод работает на клиенте, поэтому подходит для одиночной игры и серверов. Интерфейс поддерживает русский и английский языки.
